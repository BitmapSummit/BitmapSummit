◈ 4-DIGIT BITMAP SCANNER

Scans all 9,000 blocks from 1000.bitmap to 9999.bitmap — fetching inscription IDs and owner addresses directly from the Bitcoin blockchain via the ordinals.com recursive API. No API key required.

How it works: The OCI (On-Chain Index) maps each bitmap number to the exact sat it was inscribed on. For each block, the scanner fetches /r/sat/{sat} to get the inscription ID, then /r/inscription/{id} for the owner address. All data is live from the Bitcoin blockchain — no third-party APIs, no API key needed.
