⛏ BLOCK MESSAGES

Hidden messages embedded in the Bitcoin blockchain — decoded from OP_RETURN outputs. Enter any block number to reveal what was written into history.

📡 DATA SOURCE

All data is fetched live from mempool.space — a free, public Bitcoin API. No sign-up or API key needed. Calls go from your browser directly to their servers.

📦 ONE BLOCK AT A TIME

Enter any block number from block 0 to the latest tip. Each lookup fetches exactly that one block — fast, targeted, and API-friendly.

⚠️ FIRST 25 TXS ONLY

mempool.space returns 25 transactions per page. Each block may contain thousands of txs. We only scan the first 25, so some messages deeper in the block may not appear.

🔎 OP_RETURN ONLY

This page reads OP_RETURN outputs — the standard Bitcoin data field. Modern Ordinals inscriptions use Taproot witness data instead and will not appear here.

🏷️ MESSAGE TYPES

TEXT — readable ASCII/UTF-8  ·  JSON — structured data (BRC-20, Runes)  ·  URL — links  ·  BITMAP — .bitmap inscriptions  ·  HEX — binary/unreadable

💡 TIP

Try early blocks like 170 (first BTC transaction), 481824 (SegWit activation), or any recent block near the current tip to see what people are writing today.
